# Changelog

Suite versions name the drill set and judge together. A result is comparable to
another only at the same suite version and stack.

## Unreleased

Experimental v2 material for Season 2 (see [docs/v2-proposal.md](docs/v2-proposal.md)). The v1 suite is
unchanged: `drills/`, the v1 loader, `kami_drills/task.py` and the judge hash are untouched, and `kami-drills run`
never reads `drills_v2/`. No model has been run on any v2 drill; there are no v2 results.

- Cadence drills: schedule specs in `drills_v2/cadence/` scored against the game clock, and the budget-use format
  (`kami_drills/cadence.py`, [docs/v2-cadence.md](docs/v2-cadence.md)). The budget-use runner is a stub pending
  multi-step replay.
- Memory drills: don't-repeat, stale-note and notes-first specs in `drills_v2/memory/`, materialised as v1-shaped
  drills (`kami_drills/memory.py`, [docs/v2-memory.md](docs/v2-memory.md)).
- Polluted-context variants of 12 v1 drills in `drills_v2/polluted/`, generated by
  `scripts/make_polluted_variants.py` (`kami_drills/polluted.py`, [docs/v2-polluted.md](docs/v2-polluted.md)).
- v2 scoring functions: pass^k, cluster bootstrap, gap coding, ranked probability score, held-out split, item
  statistics (`kami_drills/scoring_v2.py`, [docs/v2-gap-coding.md](docs/v2-gap-coding.md)).
- Docs: the proposal, a research digest, and [docs/adapting.md](docs/adapting.md) on building drills for another
  environment. `CITATION.cff` added.
- `kami-drills check` now also runs the pytest-style v2 tests; `pytest` is a `dev` dependency group, installed by
  `uv sync`.

## 1.0.0 — first public release (2026-10-16)

Promotes rc2. The 47 drills, rules, replays and oracles are byte-identical to rc2; only
`suite_version` in each drill's `provenance` changes (`v1.0.0-rc2` -> `v1.0.0`). The published
results in `results/v1.0.0-rc2/` were run on rc2 and stand as the results of record.

- Licences: `third_party/` reproduces the kami-agent and kami-harness MIT licences verbatim,
  with a NOTICE of what was copied and from which commit.
- `runs/`: the two hosted GPT-6 Luna runs behind the 10 hosted-run drills, as example data.

## v1.0.0-rc2 (2026-10-16)

From the KamiArena drills tag `drills-v1.0.0-rc2`. Four drills fixed after a hand check of
every logged attempt; specs re-stamped, all else unchanged.

- `repeat-collect-too-far-stop`: travelling back and stopping the harvest now passes (quest 10
  needs scavenges in three other rooms, so the kami has to leave node 34).
- `stale-cooldown-retry-start`: cooldown threshold 124 s -> 100 s, matching the recorded clock
  and the drill's own fork-time `lens_kami`; the 60 s `lens_kami` row now reads 40.
- `memory-sonnet-stamina-unreliable-belief`: the correction must sit on one line and the old
  "UNRELIABLE ... call travel_to_room again" advice must be gone (the old regex matched anywhere).
- `risk-lowhp-feed-first`: `workspace_list` (file names only) is no longer forbidden before
  feeding.
- Cost: every call is priced from its token usage at pinned OpenRouter list prices
  (`results/prices-2026-10-16.json`), or its logged cost where larger; the logged `cost` field
  alone missed 30–69% of calls. Costs are approx., list prices. `report --override` merges a
  re-run of some drills into older logs.
- Results: 11 models in `results/v1.0.0-rc2/`, adding google/gemini-3.8-flash as a control.
  The 43 unchanged drills reuse the rc1 tries; the 4 fixed drills were re-run (2 tries).

## v1.0.0-rc1 (2026-10-16)

First release, extracted from KamiArena's `drills/` at tag `drills-v1.0.0-rc1`.
Release candidate until the Season 1 freeze.

- 47 drills in 8 categories (onboarding 7, progression 7, levelup 1, memory 6,
  repeat_failed 10, risk 5, stale_state 10, stalling 1), forked from KamiBench runs
  004, 005, 006 and two KamiArena hosted runs.
- Replay, rules and oracles are byte-identical to the KamiArena source; each drill adds
  a `provenance` block (credit, source transcript and fork line, chain block, stack
  pins, tools_hash, judge hash). The 10 hosted-run drills now name their own source in
  `license` instead of the KamiBench datasets.
- Stack: kami-harness 4.7.0 `df7129f`, kami-agent 0.7.5 `8e444bb`, kami-lens 1.0.5
  `e604290`, gdd `3c6f4f9`; the 9 OUTSOURCE tools are hidden.
- `kami-drills` CLI: `list`, `check`, `run`, `report`.
- Results: 10 models × 47 drills × 2 tries in `results/v1.0.0-rc1/`.
